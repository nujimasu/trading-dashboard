# スイング押し目スクリーナー — 実装仕様

ダッシュボードの全面刷新。エントリー/TP/SL の定義をやめ、
「テクニカルで対象銘柄を絞り込み、状況を分かりやすく提示する」ことに専念する。

---

## 1. スコープ

### 作るもの
- W1 パーフェクトオーダー × D1 押し目 のスクリーナー（ロング）
- 銘柄ごとの状況表示 + TradingView リンク
- 銘柄クリックで 15分足チャート + パターン描画（エントリー執行タイミング判断用）

### 削除するもの
`logic1_scan` / `logic2_scan` / `logic4_scan` / `logic5_scan` /
バックテスト系 / ポジション管理 / トレード分析
（対応する backend routes・frontend components・DB テーブルを含む）

### 残すもの
マーケットヘルス / 経済指標 / ニュース

### 今回やらないもの
- デイトレモード（5/20/50 EMA、H4 基準、M15-H1 フィルタ）
  → H4 以下の分足を全銘柄分そろえる必要があり、Polygon 無料枠では成立しない。
    スイングが動いてから、データ調達方針とセットで判断する。
- ショート
  → 将来の選択肢として、ロジックは方向を引数に取れる形にしておく。

## 3. スクリーニング条件

### 3.1 W1 パーフェクトオーダー（必須）

週足は `W-FRI` でリサンプル。SMA 20 / 50 / 200。

```
Close > SMA20 > SMA50 > SMA200          # 並び順 + 価格位置
SMA20 > SMA20[4週前]                     # 傾き
SMA50 > SMA50[4週前]
SMA200 > SMA200[4週前]
```

実測: 1,613 → 528 銘柄

**未確定週を含める（確定）。** 週足の最終バーは進行中の週。
判定が週内に入れ替わりうるため、UI に「今週は未確定」の注記を出す。

### 3.2 D1 押し目（必須）

日足 EMA20。**タッチ判定は直近3営業日の窓（確定）**。

```
直近3営業日のいずれかで low <= EMA20 * 1.02   # タッチ
現在の close > EMA20                           # 20EMA の上にいる
```

実測: 528 → 318 銘柄。「タッチ何日目か」を列で表示する。

**陽線条件 `close > open` は必須にしない。** バッジで表現する:

| バッジ | 条件 |
|---|---|
| ✅ 反発確認済 | `close > open` |
| ⏳ 押し目進行中 | 上記以外 |

理由: 必須にすると 1日あたり平均候補が 47 → 25 に半減し、
かつ「市場全体が下げた日にリストが空になる」。
押し目を探すのは市場が下げている時なので、その日に見えないのは致命的。

### 3.3 ダウ理論（日足・デフォルト ON）

確定ピボット（前後5日で最高値/最安値）から直近2山2谷を取り判定:

| 判定 | 条件 |
|---|---|
| 上昇 | 高値切り上げ AND 安値切り上げ |
| 下降 | 高値切り下げ AND 安値切り下げ |
| 中立 | どちらか片方のみ |

**「下降」だけをデフォルトで除外**（実測: 318 → 292）。
全銘柄に 上昇/中立/下降 のバッジを表示し、トグルで OFF にできる。

> 「上昇のみ必須」にしない理由: 押し目形成中は直近安値が未確定のため
> 「中立」に落ちやすく、狙っている深めの押し目を弾いてしまう。

### 3.4 ADX（デフォルト ON・閾値可変）

日足 ADX(14)、Wilder 平滑。初期値 25、UI スライダーで 15〜35 可変。

実測: 292 → 117 銘柄（閾値 25 のとき）

> ADX は押し目局面で必ず下がる指標であり、「今押している」と構造的に
> 引っ張り合う。だから固定値にせず可変にする。

### 3.5 RS 相対強度（フィルタではなく並び替えキー）

```
rs63  = 自身の63日リターン  - SPY の63日リターン
rs126 = 自身の126日リターン - SPY の126日リターン
```

デフォルトの並び順は `rs126` 降順。
フィルタとしては 8% しか削らないため、必須条件にはしない。

### 3.6 表示のみ（フィルタ OFF で用意）

- MACD（W1 ヒストグラムの向き）
- ATR%（ATR / 終値）
- 売買代金
- 52週高値からの距離

## 5. 15分足チャート（銘柄クリック時）

### データ

Polygon `/v2/aggs/ticker/{t}/range/15/minute/{from}/{to}`
無料枠は 15分遅延・履歴2年・5コール/分。
クリック時に 1銘柄 1コールなので制限内に収まる。

表示期間は直近5営業日・通常セッションのみを既定とし、
時間外表示はトグルで切替（※既定値は仮置き。使いながら調整）。

### 描画するもの

1. **日足の重要価格帯を水平線で重ねる**
   - 日足 EMA20
   - 直近スイング安値 / 高値
   - 出来高集中帯

2. **下降トレンドラインとそのブレイク**
   - 押し目中の15分足に引ける下降チャネル上辺
   - ブレイク箇所をマーク

3. **ダブルボトム / 逆三尊**
   - ネックラインを引く

4. **上昇フラッグ / 三角収束**
   - 上下2本のライン
